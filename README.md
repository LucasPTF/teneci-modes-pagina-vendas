# Protocolo Adeus Mente Acelerada

Página de vendas desenvolvida para Teneci Modes e seu workshop online ao vivo voltado a mulheres cristãs.

## Tecnologias

- Next.js 16
- React 19
- TypeScript
- CSS responsivo

## Rotas

- `/a1`
- `/a2`
- `/a3`
- `/obrigado`

As três páginas de vendas compartilham estrutura, conteúdo, oferta e identidade visual. Apenas a comunicação da área inicial muda entre as rotas.

## Execução local

```bash
pnpm install
pnpm dev
```

Abra `http://localhost:3000/a1`.

## Build de produção

```bash
pnpm build
pnpm start
```

## Informações do projeto

- Cliente: Teneci Modes
- Produto: Workshop Protocolo Adeus Mente Acelerada
- Checkout: Hotmart
- Idioma: português brasileiro

As duas fotografias do projeto foram criadas a partir da imagem profissional pública da cliente, preservando sua identidade e adequando roupa, cenário, iluminação e enquadramento à direção visual da página.
